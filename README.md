# a_click_a_map

無人機影片 → 自動建成 3D 地圖 → 用新影片做巡航定位。全部在桌面程式裡點一點完成，不用打指令。

## 先看這裡（給操作人員，四步）

1. **打開程式**：雙擊桌面「無人機自動建圖巡航系統」（第一次安裝見「從零開始」）。
2. **建圖**：左側「建圖」→ 選擇影片，或把影片和資料夾拖入清單 → 選「相機設定」並確認同一錄影模式 → 取名、選位置 → 按「開始建圖」。
3. **檢查地圖**：任務完成後，右側「成果檢視」會顯示 3D 點雲。旋轉、放大並查看連通警告，確認沒有明顯問題後按「確認地圖可用」。**沒確認不能巡航。** 原始版如需交付到另一台電腦，可另外按「匯出場域 ZIP」。
4. **巡航定位**：按成果上的「用此地圖巡航」，或在左側「巡航定位」選已確認的地圖。選巡航影片並開始；成果會顯示定位覆蓋率與航跡，無位姿的區間不連線。

右側「任務中心」可依名稱、類型搜尋，並依狀態篩選。同一時間只執行一筆任務；尚未開始的任務可取消排隊。執行時會顯示階段、已用時間，以及有資料時的**當前步驟**剩餘時間，不是整個任務的倒數。

「執行日誌」顯示最近內容，可複製預覽或按「開啟完整日誌」查看原始檔案。停止或失敗後可按「續跑」讓引擎檢查已有的階段存檔；舊任務紀錄保留，方便比對日誌。

**相機設定**：現有河濱資料可主動選「內建預設 · Parrot ANAFI（1280×720）」，僅限相同拍攝模式。換相機、視角、裁切或防手震模式時，匯入相應的已去畸變 PINHOLE JSON。匯入的設定存在這個使用者的設定目錄，下次可直接選；每筆任務保存自己的副本供續跑。混合模式請分批建圖。

原始版不會在留空時套用預設。MoGe-3 可明確選「自動估算（未驗證）」試建，正式使用前須驗證定位。命令列原始版必須加 `--intrinsics K.json`；要用內建 ANAFI 標定，可明確指定 [`configs/river_intrinsics_undistorted.json`](configs/river_intrinsics_undistorted.json)。

詳細圖文版（畫面為舊版）：[`docs/操作說明.pdf`](docs/操作說明.pdf)

## 兩個入口

| 入口 | 做什麼 |
|---|---|
| `./run.sh` — **原始版** | 一個影片資料夾 → 定位用地圖＋轉接包 |
| `./run_moge3.sh` — **MoGe-3 版** | 多支影片 → 稀疏＋稠密點雲＋定位包（見 [`moge3/README.md`](moge3/README.md)） |

兩個入口都由同一個桌面程式操作（`./gui.sh`，或桌面捷徑），只需要系統自帶的 `python3`＋GTK 3。

## 從零開始（第一次拿到這份程式）

Linux（Ubuntu 桌面）直接照打；**Windows 請先裝 WSL2＋Ubuntu 再在裡面做同樣的事**（程式放 WSL 家目錄，不支援原生 Windows，詳見工程人員安裝說明 §2、§3A）。

```bash
git clone https://github.com/1122-gggggg/a_click_a_map && cd a_click_a_map
./scripts/setup.sh              # 原始版：釘住第三方程式＋套 patch＋下載權重（EDM 權重需自備，見下）
moge3/scripts/setup.sh          # MoGe-3 版（另見 moge3/README.md）
./run.sh doctor                 # 全綠才算裝好
./安裝桌面捷徑.sh                # 桌面出現「無人機自動建圖巡航系統」，之後雙擊即可（WSL：改跑 ./gui.sh）
```

EDM 權重不會自動下載：把 `edm_outdoor.ckpt` 放到 `third_party/EDM/weights/`（或設 `ACAM_EDM_CHECKPOINT`）。
有結案包（`third_party/moge3` 已內含原始碼與權重）時改看 [`docs/工程人員安裝說明.md`](docs/工程人員安裝說明.md) §3。
操作流程（圖文，給操作人員）：[`docs/操作說明.pdf`](docs/操作說明.pdf)。

## 常見狀況

- 畫面紅字「系統尚未安裝完成」→ 引擎還沒裝好，找工程人員。
- 點桌面圖示沒反應 → 看工作列是否已有視窗；或在終端機跑 `./gui.sh` 看真正的錯誤；啟動日誌在 `acam_gui/gui.log`。
- 任務顯示「失敗」→ 選擇該任務，在「執行日誌」按「複製日誌」，連同任務名稱給工程人員。
- 成果顯示跨影片未達共視門檻 → 不要將它當成已接通的單張巡航地圖。
