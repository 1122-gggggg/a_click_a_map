# 工程人員安裝說明（一次性）

對象：負責把系統裝到目標電腦的工程人員。裝好之後，操作人員只需要看《操作說明》（PDF），雙擊桌面圖示即可建圖與定位。

## 1. 結案包內容

```
台電結案包/
├─ 0_先看這裡_操作說明.pdf         給操作人員（圖文，不需程式背景）
├─ 0_工程人員安裝說明.md           本文件
├─ 1_建圖流程/a_click_a_map/        整個程式庫（含桌面介面、兩個入口、建圖／稠密化／定位程式、patch、環境規格）
│   └─ third_party/moge3/           已備妥的第三方原始碼與權重（repo、resources、weights，約 10 GB）；envs 在目標機器上建立
├─ 2_定位流程/                      獨立的「定位包建置與使用」工具（對任意地圖建定位包）
└─ 3_烏來地圖/                      建好的烏來地圖：定位包、稀疏／稠密點雲、COLMAP 模型
```

| 流程 | 檔案 |
|---|---|
| 建圖（多影片 → 稀疏點雲 + 稠密點雲 + 定位包） | `1_建圖流程/a_click_a_map/moge3/portable_pipeline/{map_stage,dense_stage,run_pipeline}.py`、`run_moge3.sh`、`third_party/moge3/{repo,resources,weights}` |
| 定位（建定位包、在另一台電腦巡航） | `moge3/portable_pipeline/localization_stage.py` + `localization/`（同一份程式也單獨放在 `2_定位流程/`）、定位包內的 `install.py` / `run_localize.py` |
| 桌面介面 | `gui.sh`、`gui/app.py`、`gui/jobs.py`、`安裝桌面捷徑.sh` |
| 原始版入口（SALAD + EDM + KLT） | `run.sh`、`acam/`、`pipeline/`（需另外 `./run.sh setup`；介面偵測到未安裝時會自動隱藏） |

## 2. 系統需求（已驗證的環境）

- Linux 桌面（Ubuntu），NVIDIA 驅動支援 CUDA 12.8 以上。已驗證：RTX 5090（32 GB 顯示記憶體）、30 GB 記憶體。
- 建圖的 GPU 尖峰約 20 GB（GlueMap），稠密化約 8 GB；**同一張卡上不能同時跑其他吃顯示記憶體的程式**。
- 工具：`micromamba` 或 `conda`、`uv`、`ffmpeg`/`ffprobe`、`git`、`wget`；桌面介面需要 `python3-gi` 與 `gir1.2-gtk-3.0`（Ubuntu 桌面預設已裝；`zenity` 用於啟動失敗時的彈窗，選用）。
- 硬碟：程式與權重約 10 GB；環境約 30 GB；每次建圖視規模 2～20 GB 以上。
- 安裝時需要連網（下載 conda／pip 套件與 PyTorch）。

## 3. 安裝步驟

1. 把 `1_建圖流程/a_click_a_map` 複製到目標機器，**建議放在不含中文與空白的路徑**（例如 `/opt/acam`）。conda／venv 環境不能搬動，這個位置就是最終位置。
2. 建立三個環境（約 30～60 分鐘，需連網）：
   ```bash
   cd /opt/acam
   moge3/scripts/setup.sh --no-sources --no-weights
   ```
   `--no-sources --no-weights` 代表原始碼與權重已在 `third_party/moge3` 內，只建 `envs/{gluemap,moge,mvs}`。
3. 驗證環境：
   ```bash
   third_party/moge3/envs/gluemap/bin/python -c "import torch,pycolmap,pygluemap;print(torch.cuda.is_available())"
   third_party/moge3/envs/moge/bin/python  -c "import torch,flex_gemm,utils3d;print(torch.__version__)"
   third_party/moge3/envs/mvs/bin/python   -c "import torch,cv2,timm;print(torch.__version__)"
   ./run_moge3.sh --help
   ```
4. 安裝桌面捷徑（給操作人員雙擊）：
   ```bash
   ./安裝桌面捷徑.sh
   ```
   若圖示顯示成文字檔，在桌面上對它按右鍵選「允許啟動」。
5. 試跑：開啟桌面圖示，用兩支各 20 秒的短影片建圖（約 6 分鐘），再用任一個定位包做巡航（約 1 分鐘）。
6. 烏來地圖：`3_烏來地圖/定位包` 不需要重新建置；每次巡航前介面都會先執行該資料夾內的 `install.py`（把路徑轉成這台電腦的路徑，只檢查檔案大小，很快）。巡航所需的 EDM／MegaLoc 權重已包含在定位包內。

## 4. 不用介面的命令列

```bash
./run_moge3.sh a.mp4 b.mp4 --output OUT                      # 影片可為檔案或資料夾；預設 --auto_calibrate
./run_moge3.sh videos/ --output OUT --intrinsics K.json      # 已知相機（建議）：無畸變 PINHOLE JSON
# 在另一台電腦：
cd bundle && python install.py && python run_localize.py --video q.mp4 --route r1 --output result/
```

產出：`OUT/map/sparse_rgb.ply`、`OUT/dense/dense.ply`、`OUT/localization/bundle/`、`OUT/pipeline_receipt.json`。三者座標系相同。各階段可單獨執行（`moge3/portable_pipeline/*_stage.py --help`）；階段收據存在時重跑會跳過該階段。

## 5. 常用環境變數

| 變數 | 用途 |
|---|---|
| `MOGE3_TOOLKIT` | 指定 `third_party/moge3` 以外的工具包位置 |
| `LOC_PYTHON` | 建定位包與巡航使用的直譯器；其 `sys.prefix` 必須擁有 torch（conda／`uv venv` 環境），僅繼承系統 torch 的 venv 會被審計檢查拒絕 |
| `ACAM_GUI_PYTHON` | 桌面介面使用的 python（預設 `/usr/bin/python3`，需有 PyGObject + GTK 3） |

## 6. 疑難排解

| 現象 | 處理 |
|---|---|
| 介面出現「系統尚未安裝完成」 | `third_party/moge3/envs/gluemap/bin/python` 或 `weights/` 不存在：重跑第 3 步 |
| 建圖日誌出現 `CUDA out of memory` | 檢查 `nvidia-smi` 是否有其他程式佔用；殘留的舊建圖程序也會佔用（結束後再重試）。同名任務重跑會跳過已完成階段 |
| 主機記憶體不足被系統結束 | 以 `systemd-run --user --scope -p MemoryMax=24G -p MemorySwapMax=6G ./gui.sh` 啟動；大規模建圖會明顯吃 RAM |
| 巡航顯示 `torch was loaded from an unapproved location` | 用 `LOC_PYTHON` 指向 conda／`uv venv` 環境的 python |
| 桌面圖示沒反應 | 在終端機執行 `./gui.sh` 看錯誤；缺 GTK 時安裝 `python3-gi gir1.2-gtk-3.0` |
| 要看任務紀錄 | 介面所有任務存放在 `a_click_a_map/acam_gui/jobs/<id>/`（`job.json`、`log.txt`、巡航結果） |

## 7. 為另一張地圖建定位包

`2_定位流程/` 內有獨立的建置工具（見該資料夾的 `README.md`），可對任何 COLMAP 地圖與關鍵影格清單建立定位包，不需要重新建圖。

## 8. 已知限制（請告知使用單位）

- **座標不是公尺**：單目地圖只有任意尺度（Sim3）。MoGe-3 的公尺資訊在建圖時被對齊到 Pi3 的尺度後沒有保留；要公尺需已知距離、控制點或另外的尺度估計。
- 定位成功率取決於巡航影片與地圖的相似度；不同日期／光線的影片可能無法重新定位。巡航影片必須和建圖使用同一台相機（同樣的去畸變設定）。
- 純旋轉影格會標為 pose-only（不三角化）；這段遮蔽邏輯在短片測試中沒有被觸發過。
- `setup.sh` 在全新機器上的完整環境建置，只驗證了部分：`mvs` 環境用規格重建並實跑通過；`gluemap` 的 conda 規格已解算（226 套件）；pygluemap 編譯與 `moge` 環境（含 flex-gemm 編譯）沒有在乾淨機器上整套跑過。第一次安裝請預留排除問題的時間。
- 權重各有授權（Pi3、VGGSfM、Doppelgangers++、MegaLoc、MoGe-3、EDM、MVSFormer++），轉交前請確認。
